建立独立包 `hazardlib` 的骨架，只含数据结构与接口，不含 T02–T06 的任何逻辑：

- `spec/`：`HazardSpec`（含 `AgentSpec / MotionSpec / ExposureSpec / PhaseRef / TimingSpec / ReleaseSpec`）、`BenchmarkDescriptor`（含 `tier()`、`unknown_fields()`、`strict`）、`TaskContext`、`HazardInstance`、`Certificate`、`Manifest`（含 `ManifestEntry`）、共用的 `PoseSequence`。全部带 `to_dict / from_dict / validate / hash`，错误信息带点路径。

## 偏离设计文档之处与理由

1. **目录**：任务文件写 `hazardlib/spec/`，`01` §1 的目录树是 `hazardlib/src/hazardlib/spec/`。按 `01` 与验收 6 的 grep 路径取 src 布局。
2. **`tier()` 在无法判定时抛错**。设计文档没说 `unknown` 怎么参与推导；为了不违反“禁止静默降级（R15）”，我让它抛 `TierUndeterminedError`（`CapabilityError` 子类）。若协调者希望返回一个“保守下界 B”，需要你决定。
3. **Tier C 的判据**：`01` §2 只说“无物理”，BD 里没有能直接表达的字段。我取 `kinematic_pose_set == False`（危险体根本无法放置/驱动）。
4. **`state_access.eef/objects` 为 False 时判 B**：`01` §2 把 B 定义为“没有可靠接触信息或不能释放到动力学”，没覆盖这种情况；我归入 B 并在此标出。
5. **`RobotState` 增加两个可选字段**：`collision_body_names`、`collision_body_lin_vel_mps`（`01` §3.1 没有）。理由见下方“接口决定”第 14 条。均默认 `None`。
6. **`calvin.yaml` 没有照抄 `01` §2 示例**：示例里 CALVIN 的 `contact_tier: A / kinematic_pose_set: true / release_with_velocity: true` 与 `02` §2 把这些标为 [待探针] 互相矛盾；我按任务指示只填 `02` 已核实的字段，其余 `unknown`。
7. **numpy 2.x 与 Python 3.8**：验收 2 要求两种 numpy 都跑，但 3.8 装不了 numpy 2.x，实际用 3.11 换版本完成（见验收 2）。
8. **哈希格式常数 `FLOAT_SIG_DIGITS=12`、`HASH_FORMAT_VERSION=1` 在代码里，不在 YAML**。它们定义的是哈希格式（改了所有旧哈希失效），不是可调阈值；`test_source_hygiene.py` 把核心里允许存在的模块级数值常数锁定为三个：这两个加上只影响报错显示条数的 `config._SHOW_AT_MOST`。若你坚持“零数值常数进代码”，请告诉我，但把它放 YAML 会让哈希随配置文件漂移，我不建议。

## 接口决定：设计文档没写明、由我做出的决定

1. **记录严格性**：`from_dict` 拒绝多余键、拒绝缺失的必填键（无默认值的字段）、拒绝 `bool` 冒充数字、拒绝非有限浮点；`int` 可进 `float` 字段，`float` 不能进 `int` 字段。`to_dict` 总是输出全部字段，`None` 输出为 `null`。
2. **开放词表 vs 封闭词表**：`HazardSpec` 里只有 `timing.mode ∈ {nominal_time, phase_event}` 是封闭的；`family`、`agent.kind/shape`、`motion.primitive`、`exposure.anchor`、`release.mode` 都是非空字符串（族集合仍是 [开放]，原语由 T02 定义）。`motion.params`、`intensity` 是自由 JSON 字典（有限数检查）。`spec_version` 只要求非空字符串，没有“支持版本表”。
3. **`ExposureSpec`**：`offset_m` 必填（不给默认值，避免隐含零偏移）；`anchor_phase` 可选（锚点不基于时间时可为 `None`）。`PhaseRef.frac ∈ [0,1]`。
4. **`AgentSpec`**：`half_extents_m` 非空且每个 > 0（不规定长度，因形状而异），`mass_kg > 0`。
5. **BD**：全部键必填（遗漏不能掩盖未知）；任何值都可以是字符串 `"unknown"`（非 strict）；封闭词表：`loop_owner / spawn_mode / contact_tier / distance / task_entity_source / determinism.same_seed_repro`；`determinism.same_seed_repro` 的取值集合本身含 `unknown`，strict 下仍被拒。`policy_interface.notes` 必填（可写空串）。`bd_version` 只要求非空字符串。`unknown_fields()` 返回点路径。
6. **`tier()` 规则**（见偏离 2–4）：A ⇔ `contact_tier==A ∧ kinematic_pose_set ∧ release_with_velocity ∧ state_access.eef ∧ state_access.objects`；C ⇔ `kinematic_pose_set==False`；否则 B；任一决定性字段为 `unknown` 且结论依赖它时抛错。整个小节为 `unknown`（如 `state_access: unknown`）也能处理。
7. **`TaskContext`**：`layout_id` 是字符串（适配器把种子/编号转成字符串）；实体来源取 BD 的六个值（R3 的发现顺序）；`phases` 要求 `t_end≥t_start`、名称唯一、按 `t_start_s` 排序（允许有间隙，允许首尾相接）；`occupancy` 用并行数组 `points[i]` ↔ `time_s[i]`，可为空；`provenance` 自由 JSON；`support_surfaces` 复用 `host.Surface`。
8. **`PoseSequence`**（`nominal_ee_path` 与 `keyframes` 共用）：≥1 个样本，时间严格递增，四元数非零（不查单位范数）。
9. **`HazardInstance`**：`release_time_s` 与 `release_velocity` 要么都有要么都为 `None`（Tier B 的纯运动学危险）；`certificate` 在过门之前为 `None`；`onset_time_s ≤ nominal_hit_time_s`（τ ≥ 0，允许相等）；释放速度是 `ReleaseVelocity(lin_mps, ang_radps)`。
10. **`Certificate`**：`g0/g1/g2` 三态（`True/False/None=未评估`，G2 缺失即 `uncertified` 的典型情形）。
11. **`Manifest`**：存的是索引 `ManifestEntry(instance_id, spec_id, task_id, layout_id, instance_seed, instance_hash)`，不内嵌实例本体；三个哈希字段必须是 64 位小写十六进制；`instance_id` 不得重复；Manifest 自己的哈希是派生量（`Manifest.hash()`），不存进自己。
12. **`Surface`**：世界系轴对齐盒 `min_m/max_m` + `source`，顶面高度 = `max_m[2]`。
13. **`ContactObs.normal` 的方向约定**：由伙伴指向危险体（伙伴推危险体的方向）。`01` 没规定；T05 的 C6 需要沿用或改正。
14. **`RobotState`**：`gripper_opening_m` 与 `base_pose` 可为 `None`（与 BD `state_access` 对应）；新增两个可选字段是因为 `01` §3.1 说相对法向速度由核心用运动学数据补算，但 `RobotState` 只给 EEF 线速度，没有各碰撞体的速度，而 `02` §2 已提到要用 `getLinkState(computeLinkVelocity=1)` 取连杆速度。
15. **主机类型的相等性**：`Pose / RobotState / ContactObs / TimeState` 是 `eq=False` 的 dataclass（持有 ndarray，`==` 会出歧义），构造时转成 float64 数组并校验形状与有限性；`HazardHandle` 是 frozen，相等性与哈希只看 `(env, key)`，`native` 载荷被忽略。
16. **协议拆分**：`HazardHost`（必需）与 `OptionalHazardHost`（可选）是两个 Protocol；可选方法用 `getattr` 探测。`install_hooks(runtime)` 的 `runtime` 类型暂为 `Any`（T04 才有 `HazardRuntime`）。
17. **哈希规则**：键按码点排序、ASCII 转义、整数精确、浮点 `%.12g`（`-0.0` 归一为 `0`，因此 `3` 与 `3.0` 同哈希）、`NaN/inf` 抛错、`tuple/ndarray` 当列表；全文见 `hashing.py` 文档字符串。
18. **配置加载**：重复键报错；`strict` 对所有文件同时拒绝 `PLACEHOLDER` 与 `unknown`；`default_config_dir()` 先看环境变量 `HAZARDLIB_CONFIG_DIR`，再从源码文件向上、再从工作目录向上找 `configs/hazard`。
19. **骨架 YAML 的键名**：`families.yaml` 的族名取自 `00` §4 草稿表；`intensity.yaml` 的轴名取自 §4 “强度向量”列；`semantics.yaml / gates.yaml / conformance.yaml` 的键名由我依据 `00` §6、§8 与 `01` §5 起草。这些**键名是我的草稿**，所有者任务（T02/T03/T05/T06）可以改；叶子一律 `PLACEHOLDER`，没有任何数值。
